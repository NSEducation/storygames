# Story Games of Mi'kma'ki and Nova Scotia

History story games for Grade 7 students, by Mark MacFadyen (AVRCE, Nova Scotia).
Each game is one self-contained web page, shown on Google Sites with Insert > Embed > By URL.

| Page | Address |
| --- | --- |
| Main page | https://nseducation.github.io/storygames/ |
| The Words We Carry (Mi'kmaq) | https://nseducation.github.io/storygames/words-we-carry/ |
| The Day the Soldiers Came (Acadians) | https://nseducation.github.io/storygames/day-the-soldiers-came/ |
| The Milling Table (Gaels) | https://nseducation.github.io/storygames/milling-table/ |
| What the Box Remembers (African Nova Scotians) | https://nseducation.github.io/storygames/what-the-box-remembers/ |

Every story takes place in Mi'kma'ki, the unceded land of the Mi'kmaq.
